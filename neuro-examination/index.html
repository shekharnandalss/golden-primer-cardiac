How to use this set

Learn the root anchors first. Practise each movement with correct stabilization. Then work through the clinical patterns: UMN versus LMN, root versus nerve, and branch-level localization. A remembered list becomes a skill through repeated examination and observed bedside feedback.

Root labels are overlapping clinical anchors, not exclusive supplies. These are preferential tests: some muscles cannot be independently isolated. Source corrections are stated on the relevant cards. Historical drug-test images and older diagnostic terminology are explained using current context.

Examination order: observe → bulk/movements → tone → drift and power → reflexes/plantars → functional tasks → sensory/CN/cortical corroboration → localization.

Tibial

Context: Radial first dorsal hand web; median index tip; ulnar little-finger tip; deep fibular first toe web; tibial sole.

Make sense: A nerve-specific sensory territory tests a different function of the same structure. Pure motor branches and sensory overlap can still leave sensation normal.

173 / Localization

Paraspinal denervation supports a _____ lesion over a pure plexopathy.

Reveal answer, make sense and tables

Paraspinal denervation supports a Root lesion over a pure plexopathy.

Context: Map multiple nerves and roots, then use proximal branch involvement, sensory studies and paraspinal EMG if needed.

Make sense: Root and plexus lesions can share muscle weakness. Bedside findings establish a pattern; electrodiagnostic findings may be needed to distinguish pre- from postganglionic injury.

Source clarification: Sensory nerve action potentials (SNAPs) and EMG are follow-up investigations, not bedside maneuvers; normal paraspinals do not exclude a root lesion.
